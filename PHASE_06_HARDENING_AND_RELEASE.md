# Phase 06 — Hardening and Release Readiness

## Objective

Prove that the consolidated product is production-safe after feature migration.

## Required work

- accessibility and responsive pass
- end-to-end regression pass
- subscription and entitlement reconciliation checks
- security and validation review
- release-candidate hardening

## Exit criteria

- required gates are run or documented as remaining gaps
- unresolved contract conflicts are either closed or explicitly deferred
- release readiness is based on evidence, not file count

## Concurrency

Keep this phase mostly sequential. Hardening depends on a stable integrated product.
