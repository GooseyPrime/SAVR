# Archive

This directory contains historical material moved out of the active repository root.

## Structure

- `docs/legacy-firebase/`: Firebase-era deployment, webhook, and fix documentation
- `docs/historical-pr/`: completed PR plans and migration summaries
- `docs/legacy-testing/`: outdated testing/API docs tied to old architecture
- `docs/mobile-legacy/`: historical mobile implementation summaries
- `docs/web-legacy/`: superseded web README
- `docs/planning/`: older feature planning and flow reviews
- `artifacts/debug-logs/`: old HAR/debug capture files

## Intent

Active operational guidance now lives at repository root and in `web/` and `mobile/`.
Archived files are preserved for historical reference only.
